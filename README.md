# Ouiz-Time - On-Hacker-Theme(HACKER QUIZ GAME v1.0)

## About

Thisis a normal quiz game. This is a HACKER TERMINAL QUIZ built by a 14 y/o boy as a developer who codes at 2 AM with energy drinks. One mistake I do that I am currently 14 y/o but in quiz I wrote 15 y/o boy. I solve this problem later.

*Why HACKER TERMINAL - I took boring quiz challenge and converted it into a black + neon green hacking terminal. Every quetion feels like you are typing to crack a system. Every correct answer gives you access. Every wrong answer shows ACCESS DENIED*

## What Makes It Difficult and Different?

what's different:-
- True hacker aesthetic: black background, #00ff41 neon green glow, scanline animation
- Terminal typewiter effect for questions
- Glitch an shake animation on wrong answer
- Live score tracking like a hack progress bar
- 100% responsive - hack from your phone too
- Zero frameworks, zero dependencies - pure HTML5, CSS3, Vanilla Javascript. Clean code that any beginner can read.

what's difficult?
first I normally type CSS3 without any problem and I make a normal theme. After looking final look I didn't satisfy. So after delete full code I choose HACKER TERMINAL theme. hence I do double struggle to make CSS3.
